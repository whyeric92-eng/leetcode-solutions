# LeetCode Solutions

A personal collection of my LeetCode solutions, organized by language. Alongside working code, I jot down notes and takeaways on the approach, edge cases, and complexity for problems I found tricky or instructive — mainly as a study log for myself, and hopefully useful to others working through the same problems.

## Structure

```
Leetcode-Python/    Python solutions
Leetcode-C++/        C++ solutions
Leetcode-SQL/        SQL solutions (database problems)
```

Each file is named `Leetcode-<problem number> <problem title>.<ext>`, e.g. `Leetcode-1 Two Sum.py`, so you can match a file directly to its problem on [LeetCode](https://leetcode.com/problemset/).

## Notes & Insights

Where relevant, solution files include inline comments covering:
- Why a particular approach/data structure was chosen
- Time and space complexity
- Edge cases or gotchas encountered while solving

These notes are meant as a quick refresher for revisiting a problem later, not formal write-ups.

## Disclaimer

Solutions here reflect my own understanding and problem-solving process, and may not be the most optimal approach for every problem. Feedback and suggestions are welcome.
